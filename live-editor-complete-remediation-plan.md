### 5. Make source publication conflict-safe and crash-consistent
**Status: done (macOS, 2026-08-09)** — `paths.conditional_replace_file` + coordinator wire-up

Add one source-specific publication API in `src/renforge/editor/paths.py`: `conditional_replace_file(path: Path, *, expected_sha256: str, replacement_path: Path, displaced_path: Path) -> ConditionalReplaceResult`, where the frozen success result is `{published_sha256: str, displaced_sha256: str, displaced_path: Path, source_mode: int}`. Require `path` and the fsynced replacement to be no-follow regular files on one filesystem; require `displaced_path` absent with a validated same-filesystem parent; copy the current source permission bits to the replacement. First hash the no-follow source: a pre-existing mismatch raises `EditorPathError(code="STALE_SOURCE")` without writing. Then atomically exchange with `renameat2(RENAME_EXCHANGE)` on Linux or `renamex_np(RENAME_SWAP)` on macOS, or use `ReplaceFileW` with `displaced_path` as backup on Windows. On Unix the exchange leaves the old source at `replacement_path`; after hashing, move it without replacement to `displaced_path` and fsync the directory, while the already-durable journal names both locations so a crash between exchange and normalization remains recoverable. On success every platform returns the actual normalized `displaced_path`. If the displaced digest no longer equals `expected_sha256`, an arbitrary writer won the unavoidable precheck/exchange race: do not attempt another unconditional exchange or normalize away evidence; record `rollback_conflict`, retain original, staged, displaced, current source, and both candidate paths in `uncertain_paths`, then raise `EditorPathError(code="SOURCE_EXCHANGE_CONFLICT", details=...)`. The source may contain staged or a later writer's bytes, but no version is silently destroyed. If the platform/filesystem lacks the atomic primitive, raise `EditorPathError(code="SOURCE_CAS_UNAVAILABLE")`; never fall back to read-then-replace.

Route product commit, product undo, timeout rollback, explicit rollback, and startup recovery through that same primitive. Before exposing source bytes, persist and fsync the complete transaction record plus `state="publishing"`, expected original/staged digests, both candidate evidence paths, source mode, generation, and intended operation, and arm rollback protection while holding the coordinator's per-source transaction mutex. After a verified successful exchange persist `state="published"`; every later exception attempts the same source-preserving rollback and persists its structured result. An exchange that reports `SOURCE_EXCHANGE_CONFLICT` is already terminal conflict evidence and is never followed by another automatic exchange. Translate every filesystem, journal, shadow-build, lint-launch, and persistence `OSError`/`ValueError` to stable `EditorError` codes; a failed request never leaves untracked bytes.

For either recovered `publishing` or `published`: current digest equal to original persists `rolled_back` without writing; equal to staged runs conditional rollback and persists its structured result; any other digest or unreadable source persists `rollback_conflict` without writing. This covers a crash after rollback exchange but before the final journal write. `rollback_conflict` always retains the journal, original, staged, displaced/conflicting bytes, and `uncertain_paths`; successful committed/rolled-back transactions may prune temporary exchange artifacts only after their durable final state.

After `RuntimeProbe.attest` succeeds, reacquire the source transaction boundary and require the on-disk digest to equal `staged_sha256` before cancelling rollback protection or persisting `committed`. Drift becomes `POST_ATTESTATION_DRIFT` plus `rollback_conflict`; do not mark committed and do not overwrite the new bytes. ## Assumptions & contingencies

- Supported editor chrome includes 640×480 through 3440×1440. If a panel cannot display all content at the minimum size, keep its header/action visible and make only its content vertically scrollable; never move Save, Exit, or Edit off-screen and never reduce the supported floor.
- Source integrity takes precedence over availability. If atomic exchange/no-follow guarantees are unavailable on a platform or filesystem, return `SOURCE_CAS_UNAVAILABLE` and leave source bytes untouched; never fall back to a check-then-replace write.
- Bridge/control/artifact schema migration is a clean cutover. Old fixed injected files and old manifests are unowned user data and remain untouched; the next launch creates schema-1 bridge info and schema-3 ownership under the private control directory.

- The 21 live suite files remain the complete acceptance set. New behavior is added to existing task0/style-color/bar-resize/failed-gate/rotation suites; no new opt-in suite or private chrome-hiding protocol is introduced.
